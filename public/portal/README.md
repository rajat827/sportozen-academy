# Portal artwork provenance

These are granular, text-free crops from the user's supplied approved Academy references. The application renders its own editable headings, data, controls and layouts. It never uses an entire reference screenshot as a page background.

- `sportozen-mark.png` and `football-session.png` reuse the approved Home artwork; original crop coordinates and source hashes are recorded in `docs/reference/approved-ui/home-assets.json`.
- `weekly-football.png` reuses the small generic football-practice illustration from the approved parent reference. It is labelled as an illustration, not the selected child's photograph or recorded evidence.

Customer academy logos come from their saved configuration. Players without a saved portrait use an honest person placeholder; the fictional reference portrait is not assigned to a customer record. Training activity thumbnails use pitch diagrams because the current drill contract has no media field.

The user supplied the raster reference pixels. Original vector artwork, exact font identification, standalone high-resolution photographs and an independent stock licence were not provided. Self-hosted Noto fonts are used; enlarged raster crops can appear softer than the supplied composition.
